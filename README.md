# Almacén Sin TACC

Sitio web para almacén especializado en productos libres de gluten.

## 🎯 Características

- **5 páginas HTML** completamente funcionales
- **Diseño responsive** para mobile, tablet y desktop
- **Arquitectura SASS/SCSS** organizada con buenas prácticas
- **Framework Bootstrap 5.3** integrado
- **Animaciones y transiciones** suaves
- **Certificación Sin TACC** destacada

## 📱 Páginas

1. **index.html** - Página principal con hero, productos destacados y testimonios
2. **productos.html** - Catálogo completo con filtros por categoría
3. **recetas.html** - Recetas sin TACC con filtros y tips
4. **nosotros.html** - Historia, misión, equipo y valores
5. **contacto.html** - Formulario, ubicación y FAQ

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 con Flexbox y Grid
- SASS/SCSS con arquitectura modular
- Bootstrap 5.3
- JavaScript vanilla
- Google Fonts (Poppins)
- Bootstrap Icons

## 📁 Estructura SASS

```
scss/
├── _variables.scss    # Colores, espaciado, breakpoints
├── _mixins.scss       # Mixins reutilizables
├── _base.scss         # Reset, base styles, utilities
├── _components.scss   # Componentes específicos
└── main.scss         # Archivo principal
```

## 🚀 Desarrollo

### Instalar dependencias
```bash
npm install
```

### Compilar SASS (desarrollo)
```bash
npm run sass:dev
```

### Compilar SASS (producción)
```bash
npm run sass:build
```
